VISÃO GERAL

Metas

ALIMENTE SEU PIXEL

Meta Pixel & Conversions API

Não precisa de review da Meta — o token é gerado direto no Events Manager (Configurações → Conversions API → Gerar token de acesso), separado da permissão de mensagens do Instagram. Com isso configurado, o botão "Marcar como pago" na DM envia um evento Purchase pro seu pixel.
